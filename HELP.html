Relativistic Modular Audio Workstation & Live C++ DSP Math Engine
JUCE 7 / C++20 Carbon & Gold Design System Coordinate Time Clocks (γ)

1. Executive Overview

Time Dilation DAW is a state-of-the-art Relativistic Modular Audio Workstation built with native C++20 and JUCE 7. It unifies top-down visual block diagram patching with bottom-up authentic C++ / DSP math expression coding.

Every node in the workspace operates on its own local coordinate time clock (dτ = γ · dt), enabling dynamic continuous time warping (time.warp~), temporal reversal (time.retro~), gravitational stasis (time.stasis~), relativistic grid quantization (time.quantize~), and Lorentz velocity addition composition (time.math~).

2. Audio Engine Safety & Feedback Loop Guarantee

AUDIO: OFF (SAFE) Default Launch

The application unconditionally defaults to AUDIO: OFF (SAFE) on launch. The user must manually click the power toggle button in the top header bar to start audio processing execution.

1-Block Feedback Delay Stability (previousBlockBuffer)

The DSP engine automatically detects topological feedback loops in the patch graph. Destination ports in feedback paths sample from a 1-block delay buffer, ensuring 100% real-time stability without sample rate crashes or thread deadlocks.

3. Dual Perspective Guarantee

Every object block in Time Dilation DAW exposes two synchronous perspectives:

  • Top-Down Visual Inspector: Sliders, ranges, [TAP] buttons, and modulation inlets.
  • Bottom-Up Code Math: Live C++ / DSP math expression scripts evaluating $v1, $v2, $t, and tap().

5. Message Routing & Wireless Busses

  • [msg] / [message]: Dynamic symbol message box with $(...) expression math evaluation.
